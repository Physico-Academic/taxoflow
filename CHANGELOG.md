# Changelog

## 1.0.0

- Established the TaxoFlow Properties identity with plugin ID `taxoflow` and root property prefix `taxo.`.
- Standardized selector display terminology on `label` and profile-level `propertyLabels`.
- Preserved configurable profiles, dependency rules, default values, Text/List handling, Orphan Management, destructive-operation safeguards, modal dragging, and incremental inventory behavior.
- Hardened property-type resolution using active property DOM information and Obsidian metadata type-manager methods and Map/object data.
- Removed old project branding from shipped runtime code and CSS selectors.
- Excluded plugin-specific Bases integration.
- Added profile-based default folder routing with link-preserving note moves, multi-profile conflict resolution, and batch reorganization previews.
- Kept namespace conversion outside runtime as an optional dry-run-first utility.
- Added GitHub Sponsors metadata and repository validation workflows.
- Kept shipped `main.js` and `styles.css` comment-free.
- Preserved upstream MIT attribution in the license.
